01 — Workflow

The model searches before it answers.

From a plain-English prompt to production-grade advice with a citation to the exact row — in five steps, entirely offline.

  1. 01

    Your prompt

    Ask your assistant anything backend. Natural language — no special syntax.

  2. 02

    Domain detection

    Keywords map to domains — reliability, pattern, a stack — automatically.

  3. 03

    BM25 + synonyms

    Pure-Python BM25 over 35 domain CSVs, synonym-expanded, mtime-cached. Every hit carries a confidence score.

  4. 04

    Cited answer

    The model answers with the right library and pattern, citing the row. Reviewers can verify.

  5. 05

    Cross-domain synthesis

    A saga answer pulls pattern + messaging + consistency + reliability at once.

11 — FAQ

Questions from code review.

Does it call the network or another model?

No. Retrieval is pure-Python BM25 over local CSVs with synonym expansion and an mtime-cached in-memory index. Optional extras add embeddings (backendpro[semantic]) or a cross-encoder rerank (backendpro[rerank]), with graceful fallback.

How is this different from a docs MCP like Context7?

Docs servers give your agent up-to-date library APIs. Backend Pro Max gives it architectural judgement — which pattern, which trade-off, what not to do and how severe it is — with a citation. They complement each other.

Which assistants does it support?

Claude Code, Cursor, Windsurf, GitHub Copilot and Continue via backendpro --load <tool>, plus any MCP-compatible agent via backendpro --mcp, and the CLI on its own.

How do you keep 685 rows from going stale?

Every row has a Last Updated date. A weekly GitHub Action flags rows older than 18 months and broken source URLs; 239 golden-query assertions guard ranking quality on every PR.

What does it cost?

Nothing. It's MIT-licensed open source and needs Python 3.8+ with zero runtime dependencies.

Can I add my team's own rules?

Yes — rows are plain CSVs with a validated schema. See CONTRIBUTING.md; backendpro coverage shows which domains are thin.
