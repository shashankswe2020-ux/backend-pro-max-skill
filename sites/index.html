FAQ

Before you install

Does it need a network connection?

Default BM25 search runs over local CSVs without a model or network call. Optional semantic search and reranking use model dependencies that may need downloads. Your AI client and this website have their own network requirements.

How does it differ from a docs MCP like Context7?

Backend Pro Max stores curated guidance on patterns, trade-offs and common mistakes rather than a live library API reference. Follow the linked sources for details and current version requirements.

Which assistants does it support?

Claude Code, Cursor, Windsurf, GitHub Copilot and Continue via backendpro --load <tool>, plus any MCP-compatible agent via backendpro-mcp after installing backendpro[mcp], and the CLI on its own.

How current is the guidance?

Check each row's Last Updated date and linked source. Weekly freshness scans flag older entries for review; they do not guarantee that every recommendation is current.

What does it cost?

Nothing. It's MIT-licensed open source and needs Python 3.8+ with zero runtime dependencies.

Can I add my team's own rules?

Yes. Rows are plain CSVs with a validated schema. See the contribution guide; backendpro coverage reports gaps in domain coverage.
